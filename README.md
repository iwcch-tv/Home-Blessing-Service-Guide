# 무릎으로 짓는 축복의 우리 가정

대한예수교장로회 일원중앙교회 "하루시작 3분묵상" 축복기도문을 모바일 웹페이지로 만든 프로젝트입니다.

## 바로 보기

https://iwcch-tv.github.io/Home-Blessing-Service-Guide/

## 파일 구성

- `index.html` — 전체 페이지. 폰트를 제외한 이미지 등 모든 리소스가 파일 하나에 들어 있어 이 파일 하나만 저장소에 올리면 바로 동작합니다.
- `thumbnail.jpg` — 카카오톡, 페이스북 등에 링크를 공유했을 때 뜨는 미리보기 이미지입니다. index.html과 같은 폴더에 함께 있어야 합니다.

## 주요 기능

- 요일별 탭(월~토)을 날짜와 함께 표시하고, 접속한 날짜에 맞는 요일이 자동으로 열립니다.
- 성경 본문은 개역개정을 기본으로 보여주고, 새번역으로 전환할 수 있습니다.
- 교회소식·교회안내 탭에서 행사 소식과 교회 기본 정보를 함께 볼 수 있습니다.
- 공유하기, 링크 복사, 인쇄/PDF 저장 버튼을 제공합니다.
- 라이트 모드와 다크 모드에 모두 자동으로 맞춰집니다.

## 매달 새 주차 추가하기

새 주차의 카드뉴스 원고(요일별 성경 구절·본문·삽화)와 그 주의 날짜 범위를 Claude에게 전달하면, 기존 주차 뒤에 이어 붙여 index.html을 다시 만들어 줍니다. 완성된 파일을 그대로 이 저장소에 덮어쓰면 됩니다. 페이지를 열면 항상 가장 최근에 추가된 주가 기본으로 보이고, 화면 상단의 화살표로 이전 주들을 넘겨볼 수 있습니다.
